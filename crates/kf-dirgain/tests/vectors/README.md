# Conformance fixtures

## `scale_vectors.json`

Copied byte for byte from Open Directional DPI (`github.com/0zLloen/open-directional-dpi`,
`tests/vectors/scale_vectors.json` at commit `c177d23c2d6243f676ab49a9531ae120fd0d896c`;
unchanged up to `3ea27cf`). MIT License, Copyright (c) 2026 OzLloen and Open Directional
Sensitivity Contributors. SHA-256 `f8b41442aaa7a4201aea559ebcb0f5c23669c320aaec8b6afd08828d1cf15604`.

The C reference engine generates it (`tests/gen_vectors.c`): 8 serialized 28-byte profiles,
each with 324 `[dx, dy, scale_q16_16, octant]` rows of `ddpi_compute_scale_q16_16` output
(2592 in total). `../scale_vectors.rs` embeds it with `include_str!` (no file I/O, so it also
runs on `wasm32-wasip1`), deserializes each profile, requires `serialize` to reproduce the
bytes, and requires `compute_scale_q16_16` to match every row exactly.

Do not edit it by hand. To refresh, regenerate it in the C repository
(`make -C tests vectors`) and copy it here, updating the commit and hash above.
